# Quiz App

An interactive quiz web application built using Object-Oriented Programming (OOP) principles and an external API to dynamically retrieve quiz questions and answers. This app features real-time input validation, session management, and a responsive, user-friendly interface.

## Features

- Dynamic question retrieval using an external API
- Object-Oriented Programming (OOP) for scalable and reusable code
- Real-time input validation and feedback for each question
- Responsive, user-friendly design with intuitive navigation
- Session management to store user progress across multiple quiz attempts
- Smooth transitions and dynamic updates to enhance user experience

## Technologies Used

- HTML
- CSS
- JavaScript
- External API for quiz data
- Object-Oriented Programming (OOP)
